CHENXIN FILTERS DEMO

To run:
1. Extract the folder.
2. Open index.html in a modern browser (double-click).
3. Browse products, add items to cart, and submit a demo order.
4. Open admin/index.html to explore the demo admin panel.

Demo note:
This is a browser-only prototype. It uses localStorage and only shares demo data within the same browser/device. No live payment is processed. Social links and payment logos are illustrative. Some image/font assets may require internet connectivity.
